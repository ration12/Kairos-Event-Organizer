# Kairos Policy Site

Public Privacy Policy and Terms and Conditions for **Kairos - Make It Count**.

This static site can be hosted directly with GitHub Pages. Both pages share `styles.css` and support responsive layouts, dark mode, keyboard navigation, and print-friendly formatting.

## Pages

- `privacy.html` - Privacy Policy
- `terms.html` - Terms and Conditions

## Local preview

Open either HTML file in a browser, or run `python3 -m http.server 8000` from this directory and visit `http://localhost:8000/privacy.html`.
